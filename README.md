# Customer Segmentation using K-Means Clustering

## Overview
This project uses the K-Means Clustering algorithm to group retail store customers based on their purchasing behavior. The segmentation is performed using the Mall Customers dataset from Kaggle.

## Dataset
- **Dataset:** Mall Customers Dataset
- **Source:** https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Features Used
- Annual Income (k$)
- Spending Score (1-100)

## Project Workflow
1. Import libraries
2. Load the dataset
3. Explore the dataset
4. Check missing values
5. Select features
6. Find the optimal number of clusters using the Elbow Method
7. Train the K-Means model
8. Visualize customer clusters
9. Analyze cluster results

## Results
- Customers are divided into **5 clusters**.
- The Elbow Method is used to determine the optimal value of K.
- Cluster centers are visualized on a scatter plot.

## Output
The notebook generates:
- Elbow Method graph
- Customer cluster scatter plot
- Cluster-wise customer analysis
